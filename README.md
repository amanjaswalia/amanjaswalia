- **Frontend**: React, Next.js, React Native, Angular, TypeScript, Tailwind CSS
- **Backend**: Node.js, Express, NestJS, Django, FastAPI, GraphQL, PHP/Laravel
- **Database**: PostgreSQL, MongoDB, MySQL, Firebase/Firestore
- **AI**: Claude AI, OpenAI/GPT, Prompt Engineering, Jasper AI, Midjourney
- **Cloud & Tools**: AWS (EC2, S3), Vercel, Docker, Git, Claude Code, Cursor AI

## Features

- Multi-language support (English, French, German, Spanish, Dutch, Italian)
- Dark/light theme toggle
- Responsive design (mobile-first)
- SEO optimized with JSON-LD structured data, sitemap, and OpenGraph
- Contact form via WhatsApp integration
- Floating WhatsApp button
- Emergency hiring banner
- Animated sections with Framer Motion
- Google Maps embed

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash

```
